# 統計のアトリエ — Statistics Lab

確率論と統計学を分野別に学び、両者の関係を確かめる日本語の学習アプリ。ビルド不要の HTML / CSS / JavaScript で動きます。

## できること

- 14種類の分布のパラメータをスライダーで操作
- 各分布に、現在の設定の読み方・操作の順番・統計へのつながりを表示
- 二項分布で、試行回数を4倍にした場合の回数と割合の変化を比較
- 確率量・密度関数と累積分布関数、指定区間の確率を表示
- 期待値、分散、標準偏差の連動表示
- 積率母関数の存在範囲と平均・分散への導出
- 全13章の講義ノート（基礎、標本分布、推定、信頼区間）
- 35問の計算・証明演習、採点と解説、ブラウザ内の学習履歴
- 確率論2 第1〜6回に対応した6章・27問（特性関数、収束、不等式、弱・強大数の法則）
- 確率論と統計学を結ぶ6つの橋、各分野への相互リンク
- 概収束・確率収束・L¹収束を比べる3つの対話図
- 標本比率の二項確率とChebyshev上限の比較（正規近似なし）
- スマートフォン対応、キーボードによる操作

## 起動

`index.html` をブラウザで開くだけで利用可能です。ローカルサーバーを使う場合：

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。外部JavaScriptライブラリ、外部フォント、APIキーは不要です。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch** で `main` / `/ (root)` を選ぶと公開できます。

## 検証

```sh
node test.js
```

既知の分布間の恒等式、CDFの範囲と単調性、離散確率の正規化、パラメータ端点、両分野の画面生成、採点、学習履歴の互換性、相互リンク、タイプライターの区間分割、二項確率とChebyshev上限の整合性を確認します。

## 教材を追加する

教材ごとの内容は描画から分離しています。追加方法は [CONTENT_GUIDE.md](CONTENT_GUIDE.md) を参照。既存の学習履歴を壊さないため、問題IDは変更しません。新しいPDFはブラウザへアップロードするのではなく、公開する解説・演習を確認して教材モジュールに追加します。

- `data.js`: 既存の統計学と分布データ
- `probability.js`: 確率論の教材モジュール
- `curriculum.js`: 分野の登録と相互リンク
- `interpretation.js`: 分布の操作に連動する解説
- `learning-math.js`: 収束実験と二項確率の計算
- `course-ui.js`: 分野別の解説・演習・対話図の表示

## 記号・数値表示

- 幾何分布と負の二項分布は成功までの**失敗回数**。
- ガンマ分布の β は**率**（尺度の逆数）。
- 講義ノートの S² は不偏標本分散。参照資料の S に相当。
- 分位点は**上側確率**で指定。
- グラフには有限範囲だけを表示し、表示範囲に含まれる確率を付記。密度が発散する端点は縦軸上限で切り取り、その旨を表示。確率を再正規化していません。
- 連続CDFは不完全ガンマ関数・不完全ベータ関数などで数値計算。演習の許容誤差は最大で絶対誤差0.0001または正解の0.1%。
- t・F・コーシーでは通常のMGFが存在しないことと、積率の存在条件を区別しています。

## コンテンツ

「統計学1及び演習」No.1–13 の構成・記号に沿って、解説と追加問題を独自に記述。元のPDFはリポジトリに含めません。No.7の一様分布に対するCR下限、No.8 C3の一般性、No.12の分散比の向きについて補足しています。全問題の逐語的な転載や全設問の解答集ではありません。

確率論2 第1〜6回の主要テーマも、直感・具体例・定義・証明の順で解説。第1回の確率1の事象の独立性の例外を補足しています。確率論側の幾何分布は成功までの試行回数、統計学側のグラフは成功前の失敗回数という定義の違いを明示。中心極限定理などの橋渡しの説明は、資料の演習を理解するための補足です。

## プライバシー

メールアドレス・実名・個人のローカルパス・認証情報をアプリに含めません。元PDF・抽出テキスト・ページ画像も公開しません。学習履歴はlocalStorageにのみ保存し、外部に送信しません。解析ツール・外部フォントは使用しません。GitHub Pages自体の配信通信は発生します。公開リポジトリとURLからGitHubの所有アカウントは分かります。
